# ryan.kiwi

my personal website. built with next.js and D3.js. mixed SSG, SSR and CSR. 

`public/maps.json` - data source for mapping projects
`public/projects.json` - data source for programming projects
`public/home.txt` - data source for home page
`public/posts/*.md` - data source for blog posts (md with frontmatter)

`src/app` - webapp and navigation routes
`src/assets` - vector graphics
`src/content` - 'commands' / pages
`src/types` - type definitions for ssg json files
`src/ui` - other components
`src/visuals` - d3 data visualisation components
